How to Create a Test

Quick steps for quiz creation & Google Sheets integration
Ready to launch your quiz? This guide walks you through the essentials—uploading questions, setting rules, and connecting results to Google Sheets.

1. Steps to Create a Test

  1. Go to the Create Test page.
  2. Fill in these fields:
    • Test Name: Give your quiz a name.
    • Test Description: Add a brief description.
    • Questions (PDF or JSON): Upload your questions file.
      PDF Format Required: 
      
Q1: What is the capital of France?
a) Berlin
b) Madrid
c) Paris
d) Rome
Answer: c

Q2: Which planet is known as the Red Planet?
a) Earth
b) Mars
c) Jupiter
d) Venus
Answer: b
      • Start each question with Q1:, Q2:, etc.
      • Options: a), b), c), d)
      • Correct answer: Answer: [option letter]
      • Leave a blank line between questions.
      Other formats may not convert correctly.
    • Timer Type: Choose Overall or Per Question.
    • Maximum Allowed Cheat Count: Set cheat attempt limit.
    • Allow Keyboard During Test?: Yes or No.
    • Google Sheet URL: Paste your Google Apps Script Web App URL (see below).
    • Rules: Add any special instructions.
  3. Click Create Test to save and activate.

2. Google Apps Script Web App URL

  1. Create a Google Apps Script Project:
    • Go to Google Apps Script and click New Project.
  2. Write the Script: 
    
function doPost(e) {
  var sheet = SpreadsheetApp.openById('YOUR_SHEET_ID').getSheets()[0];
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.name,
    data.branch,
    data.year,
    data.email,
    data.cheatCount,
    data.score
  ]);
  return ContentService.createTextOutput("Success");
}
    • Replace 'YOUR_SHEET_ID' with your Google Sheet's ID.
  3. Deploy as Web App:
    • Click Deploy > New deployment.
    • Select Web app and set access to Anyone.
    • Click Deploy and copy the Web App URL.
  4. Use the Web App URL: 
    
<input
  class="form-input"
  type="url"
  name="sheetUrl"
  placeholder="Paste your Google Apps Script Web App URL"
  required
/>
  5. Test:
    • Submit a quiz and check your Google Sheet for results.

How to Find Your Google Sheet ID

You can get your Google Sheet ID directly from the sheet’s URL.

For example, if your sheet URL is:
https://docs.google.com/spreadsheets/d/1aBcDeFGhijkLMNOPqRstuVWxyZ1234567890abcdEFg/edit#gid=0
The part between /d/ and /edit is your Sheet ID:
1aBcDeFGhijkLMNOPqRstuVWxyZ1234567890abcdEFg
That’s the value you’ll replace 'YOUR_SHEET_ID' with in your Apps Script code.

Tip: Just copy everything after /d/ and before /edit in your sheet’s URL.
Note: Only use the Apps Script Web App URL, not the regular Google Sheet URL. Make sure your script and sheet permissions allow writing from your web app.

How to View Your Quiz Results

  1. Open your Google Sheet using the Sheet ID you set in your Apps Script code.
    For example, go to:
    https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit
  2. Check the first sheet/tab (usually named "Sheet1" unless you renamed it).
  3. Each quiz submission will appear as a new row, with columns for name, branch, year, email, cheat count, and score.
  4. If you don't see new data, make sure your Apps Script is deployed and your quiz is submitting results to the correct Web App URL.
Your results are updated in real time as participants submit their quizzes!
